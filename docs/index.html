01

Choose the sky region

Use daytime images dominated by sky. Buildings, trees and sun glare affect the color threshold. The circular region applies only to threshold estimates; CNNs use the full image.

02

Make the method visible

Pixel coverage uses the normalized red–blue difference. Two ResNet18 models predict cloud amount and cloud type separately. Their softmax scores have not been probability-calibrated.

03

Keep the evidence in view

Models use deduplicated labeled data. A separate validation set selects the epoch; the final test set is evaluated once. Random-split results may differ from performance on other devices and new scenes.
